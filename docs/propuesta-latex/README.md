# Agentes como configuración gobernada — documento (LaTeX)

**Overleaf:** New Project → Upload Project → sube este zip. Compilador: pdfLaTeX (por defecto).
Archivo principal: `main.tex`. La bibliografía (`referencias.bib`) se procesa sola.

- `sections/` una sección por archivo (00 portada … 09 anexos)
- `figures/` las 22 figuras en TikZ (se compilan dentro del documento)
- `mermaid/` versiones Mermaid de las mismas figuras, para el README del repositorio
- `estilos.tex` paleta de colores, estilos de diagramas y cajas
